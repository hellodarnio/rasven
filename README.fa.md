Rasven یک تلفن نرم‌افزاری رایگان برای اندروید است که خط کاری سازمان را به گوشی اندرویدی می‌آورد. برای استفاده باید از قبل در یک **PBX سازمانی سازگار با IAX2** حساب داشته باشید؛ سرویس تلفنی، PBX یا حساب آن از طرف Rasven ارائه نمی‌شود.

## دریافت

<p align="center"><a href="https://github.com/hellodarnio/rasven/releases/tag/v1.0.0"><strong>دریافت APK نسخهٔ Rasven v1.0.0</strong></a></p>

APK در [صفحهٔ Release گیت‌هاب](https://github.com/hellodarnio/rasven/releases/tag/v1.0.0) قرار دارد. **این مخزن فعلاً خصوصی است**؛ بنابراین دریافت فایل از GitHub به دسترسی مخزن نیاز دارد. نسخهٔ اول Rasven در بازارهای اپلیکیشن هم قابل دریافت است.

> **نکتهٔ نسخه:** بستهٔ بازار با همین snapshot سورس و گواهی امضای آن تطبیق داده نشده است. ممکن است این APK روی نسخهٔ نصب‌شده از بازار، به‌عنوان به‌روزرسانی پذیرفته نشود.

## معماری

Rasven یک کلاینت اندرویدی است و کد سیگنالینگ IAX2 و انتقال UDP در خود برنامه قرار دارد. صدای تماس از موتور رسانهٔ G.711 و رابط‌های صوتی اندروید عبور می‌کند. PBX یک سرور موجود و تحت مدیریت سازمان است و در این مخزن قرار ندارد.

<p align="center">
  <img src="docs/media/readme/architecture-fa.svg" alt="معماری Rasven: رابط اندروید، کلاینت IAX2، رسانهٔ صوتی و PBX بیرونی سازمان" width="100%">
</p>

برنامه برای ثبت حساب به دسترسی شبکه به PBX نیاز دارد. آدرس سرور، پورت، داخلی یا نام کاربری و رمز را از مدیر PBX بگیرید.

## پیش‌نیازها

- اندروید ۸٫۰ (API 26) یا جدیدتر
- حساب کاربری در PBX سازمانی سازگار با IAX2
- دسترسی شبکه به همان PBX
- مجوز میکروفن و اعلان برای تماس؛ دسترسی مخاطبین اختیاری است

## ساخت از سورس

یک JDK سازگار و Android SDK نصب کنید، سپس مخزن را در Android Studio باز کنید یا Gradle Wrapper را از ریشهٔ پروژه اجرا کنید.

**Windows PowerShell**

```powershell
.\gradlew.bat :app:assembleDebug
```

**Linux یا macOS**

```sh
./gradlew :app:assembleDebug
```

APK آزمایشی در مسیر `app/build/outputs/apk/debug/` قرار می‌گیرد. این فایل برای توسعه و ارزیابی است و نسخهٔ عمومیِ امضاشده محسوب نمی‌شود. ساخت نسخهٔ انتشار به شناسهٔ تأییدشدهٔ برنامه و اطلاعات امضا نیاز دارد؛ این مقادیر را بیرون از مخزن نگه دارید و فایل کلید یا رمزها را commit نکنید.

## وضعیت اعتبارسنجی

گزارش handoff مورخ ۲۰۲۶-۱۰-۲۳ برای این snapshot سورس، **۳۳۲ آزمون موفق JVM** و اجرای هدفمند روی دستگاه اندرویدی با نتیجهٔ **۸ از ۸** را ثبت کرده است. این بررسی‌ها پیش از تغییر اخیر تنظیمات امضا اجرا شده‌اند. یک اجرای جداگانه از مجموعهٔ کامل دستگاه **۱۹۰ از ۱۹۵** بود و پنج خطا داشت؛ بنابراین آن مجموعه سبز نبود. پس از تغییر تنظیم امضا، ساخت APK تازه‌ای در handoff ثبت نشده است.

سازگاری زنده با PBX، انتقال مشاوره‌ای تماس و رفتار طولانی‌مدت در پس‌زمینه و Doze برای این snapshot هنوز تأیید نشده‌اند. نتیجه‌های آزمون تاریخی هم APK فعلی بازار را تأیید نمی‌کنند.

# Rasven برای اندروید

Rasven یک تلفن نرم‌افزاری رایگان برای اندروید است که برای اتصال به سامانهٔ تلفنی سازمانی سازگار با IAX2 طراحی شده است. برای استفاده، باید از قبل حسابی روی PBX سازمان داشته باشید؛ Rasven سرویس تلفنی یا حساب PBX ارائه نمی‌کند.

**دانلود:** نسخهٔ اول Rasven تکمیل شده و اکنون از بازارهای اپلیکیشن قابل دریافت است. این مخزن شامل سورس است و APK بازار یا GitHub Release را میزبانی نمی‌کند. [English](README.md)

**مشخصات این snapshot سورس:** تنظیم Gradle نسخهٔ ۱٫۰٫۰ (versionCode 1)، شناسهٔ darnio.rasven.android و حداقل Android API 26 را مشخص می‌کند. هنوز تطابق APK بازار با همین snapshot سورس تأیید نشده است.

## امکانات موجود در سورس

- راه‌اندازی حساب IAX2 و نمایش وضعیت اتصال
- مسیرهای تماس ورودی و خروجی
- مخاطبین، سوابق تماس و تنظیمات تماس
- زبان انگلیسی به‌صورت پیش‌فرض و امکان انتخاب فارسی

این موارد دامنهٔ فعلی سورس را توصیف می‌کنند و به‌معنای تأیید عملکرد روی همهٔ PBXها و دستگاه‌ها نیستند.

## پیش‌نیازها

- اندروید ۸٫۰ (API 26) یا جدیدتر
- حساب IAX2 که مدیر سامانهٔ تلفنی سازمان در اختیارتان بگذارد
- دسترسی شبکه به همان PBX
- مجوز میکروفن و اعلان برای تماس؛ دسترسی مخاطبین اختیاری است

آدرس سرور، پورت، داخلی یا نام کاربری و رمز را از مدیر PBX بگیرید. مقدار پورت و تنظیمات شبکه به سامانهٔ شما بستگی دارد.

## ساخت APK آزمایشی

یک JDK سازگار و Android SDK نصب کنید، سپس پروژه را در Android Studio باز کنید یا از ریشهٔ مخزن Gradle Wrapper را اجرا کنید.

در Windows PowerShell:

    .\gradlew.bat :app:assembleDebug

در Linux یا macOS:

    ./gradlew :app:assembleDebug

APK آزمایشی در مسیر app/build/outputs/apk/debug/ ساخته می‌شود. این فایل برای توسعه و ارزیابی است و انتشار عمومیِ امضاشده محسوب نمی‌شود.

تنظیمات امضای انتشار از اطلاعاتی استفاده می‌کند که بیرون از این مخزن نگهداری می‌شوند. فایل کلید، رمز یا تنظیمات امضا را commit نکنید.

## وضعیت آزمون و موارد تأییدنشده

handoff مورخ ۲۰۲۶-۱۰-۲۳ برای همین snapshot سورس، موفقیت ۳۳۲ آزمون JVM و ۸ مورد از ۸ آزمون هدفمند روی دستگاه اندرویدی را گزارش کرده است. این آزمون‌ها پیش از تغییر اخیر تنظیمات امضا اجرا شده‌اند. یک اجرای جداگانه از مجموعهٔ کامل آزمون‌های دستگاه ۵ خطا داشت (۱۹۰ از ۱۹۵)؛ بنابراین مجموعهٔ کامل سبز نبوده است. این نتایج مربوط به snapshot سورس‌اند و APK فعلی بازار را تأیید نمی‌کنند.

سازگاری زندهٔ همین snapshot با PBX، انتقال مشاوره‌ای تماس و رفتار طولانی‌مدت در پس‌زمینه و Doze هنوز تأیید نشده‌اند. در handoff ساخت APK تازه پس از تغییر تنظیمات امضا ثبت نشده است؛ تطابق سورس GitHub با بستهٔ بازار هم هنوز تأیید نشده است.

## حمایت مالی با ارز دیجیتال

استفاده از Rasven رایگان است. جزئیات حمایت داوطلبانه پس از آماده‌شدن در این بخش قرار می‌گیرد.

- ارز یا توکن: بعداً اضافه می‌شود
- شبکه: بعداً اضافه می‌شود
- آدرس عمومی کیف پول: بعداً اضافه می‌شود

برای هر آدرس، نام ارز و شبکهٔ دقیق آن کنار هم نوشته خواهد شد.

هنوز فایل مجوز نرم‌افزار در این مخزن قرار نگرفته است. پیش از انتشار عمومی سورس، نگه‌دارنده مجوز متن‌باز را انتخاب و اضافه می‌کند. راهنمای مشارکت هم در همان مرحله منتشر خواهد شد.
